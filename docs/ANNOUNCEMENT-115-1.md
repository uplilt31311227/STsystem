## 為什麼一定要提「強制重新整理」

系統部署在 GitHub Pages，靜態檔案的快取時間是 10 分鐘，而部分被動態載入的程式檔沒有版本參數
（理由見 `docs/STAGE0-DEPLOY.md`），瀏覽器可能沿用舊檔。舊檔配新資料會出現「功能點了沒反應」
這類難以解釋的症狀——2026-07-31 上線後的 v2- 頁籤無反應就是同一類問題。
一次強制重新整理可以完全避開這個窗口。
